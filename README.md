# Enunciado: Vamos controlar os LEDs!

O projeto utiliza um botão como entrada para controlar dois LEDs como saída. A cada clique no botão, o Arduino altera o estado dos LEDs, seguindo uma sequência pré-definida.

## Funcionamento

1º clique: o LED 1 é ligado.
2º clique: o LED 1 é desligado e o LED 2 é ligado.
3º clique: os dois LEDs são desligados e a contagem de cliques é reiniciada.
Pinos utilizados
Botão: pino 5
LED 1: pino 2
LED 2: pino 4

| Qtd | Componente                   |
